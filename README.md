# 🎧 聽越語．拼台羅（Similar sounds VN）

教師在大螢幕投影，即時組合越南語的子音、母音、尾音、聲調並播放越南語音；學生聽音後練習拼出相同組合的**台語羅馬字**，教師再依序公布「聲母 → 韻母 → 聲調 → 台語羅馬字」，並可播放台語音。介面與操作完全比照〈[聽韓語．拼台羅](https://cyril-mingdao.github.io/Similar-sounds/)〉〈[聽日語．拼台羅](https://cyril-mingdao.github.io/Similar-sounds-JP/)〉。

## 頁面

| 檔案 | 用途 |
|---|---|
| `index.html` | 投影頁（上課用） |
| `review.html` | 聲調審聽頁（教師審聽、修正拼音與聲調） |

## 操作

- 左側點子音、母音（尾音可不選，聲調預設 ngang）→ 自動播放越南語音
  - 拼寫自動依越南語正字法：c 接 i、e、ê 寫成 k，接 oa、oe 寫成 qu（quan）；g、ng 接 i、e、ê 寫成 gh、ngh；ia、ua 接尾音寫成 iê、uô
  - ă、â 一定要接尾音；入聲尾音 -p -t -c -ch 只能配 sắc（á）或 nặng（ạ）
- 舞臺上的越南語拼寫可點，另開 [Glosbe 越中辭典](https://zh.glosbe.com/vi/zh/hi) 查這個字的意思
- 越南語聲調與臺語聲調的對應：入聲 sắc → 第 8 調、nặng → 第 4 調；huyền → 第 3 調；ngang 依音高判為第 1 或第 7 調
- 牌卡右上角 🔊 播單音：子音念「子音＋a」，母音單念，尾音念「a＋尾音」，聲調念 a 的六個調；標題旁 ▶ 依序輪播整列，速度鈕切換 0.5～1.75 倍
- 點「聲母」「韻母」「聲調」「台語羅馬字」卡片可個別公布；公布後點台語羅馬字播放台語音
- 公布後點「聲母」「韻母」卡，播放詹宗龍老師自行錄製的聲母、韻母音檔（與〈羅馬字拼音互動遊戲〉同一批，`audio_spell/`）
- 簡報筆 ▶：聲母 → 韻母 → 聲調 → 答案 → 播台語音 → 隨機下一題；◀ 倒退
- 隨機出題採洗牌制：題庫每題各出一次，全部輪過才重新洗牌
- 快捷鍵：空白 播放｜S 慢速｜Enter 依序公布｜A 全部公布｜R 隨機｜T 倒數｜Esc 清空

## 題庫

只收越南語與台語羅馬字**近似度 100%** 及教師審聽確認的音節（子音 無・c・h・m・n・ng・s・t・th・x；母音 a・ê・i・o・u；聲調 ngang・huyền，及入聲 sắc・nặng），其餘組合顯示「無近似音」並說明原因。題庫已經教師審聽修正（`tone_overrides.json`，2026-10-25）。

與臺語有近似音的組合都預錄越南語音；其餘組合（ph、v、ơ、ư、â 等）改用瀏覽器內建的越南語語音播放（電腦沒有越南語語音時無法播放）。

## 素材來源

- 越南語音檔：Microsoft Edge 語音合成（vi-VN-HoaiMyNeural，北部河內音），起音淡入並統一音量
- 台語音檔（`audio_tw/`）：部分取自教育部《[臺灣台語常用詞辭典](https://sutian.moe.edu.tw/)》同音讀單字詞條的音檔（著作權屬教育部，依[創用CC 姓名標示－禁止改作 3.0 臺灣](https://creativecommons.org/licenses/by-nd/3.0/tw/)授權條款以原檔使用，未經剪輯或改作），其餘由陽明交大台語 TTS（男聲、台北腔；v3 起由女聲改男聲） 產生
- 台語羅馬字依教育部《臺灣台語羅馬字拼音方案》
